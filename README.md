# SpaceEco System - ISS Waste Management

A smart system designed to manage, track, and recycle waste on the International Space Station (ISS).

## 🔗 Check My Project
[**Click here to view the live website on GitHub Pages**](https://dunia-khanfa.github.io/SpaceEcoSystem-PROJECT-/)

## 📝 Project Overview
This project was developed as part of the Information Systems B.Sc. program at **The Academic College of Tel-Aviv, Yaffo**. The system provides astronauts with a digital interface to log waste data in zero-gravity conditions, monitor real-time bin capacities, and access NASA-standard safety protocols for hazardous materials.


## 🚀 Key Features
* **Real-Time Dashboard:** Monitor waste levels and bin capacities via a dynamic tracking interface.
* **Data Validation:** Integrated client-side validation using **JavaScript** to ensure accurate logging of weight and material types.
* **Server-Side Processing:** Secure data handling and storage using **PHP** and **MySQL**.
* **Learning Hub:** Interactive training modules featuring audio briefings and video demonstrations for debris containment.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6), jQuery, Bootstrap 5.
* **Backend:** PHP.
* **Database:** MySQL.
